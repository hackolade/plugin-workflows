# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** in this repository. Do not open a public issue or pull request for a vulnerability.

This repository is a read-only published copy: fixes are made in Hackolade's internal source repository and published with the next release.

The workflows and actions of this repository are referenced by other repositories through the `v1` tag; fixes are released as a new `v1.x.y` tag and `v1` is moved to it.
